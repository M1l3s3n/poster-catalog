# Poster-Catalog

Frontend application developed for the "IT-Projects" course.

The project represents a minimal catalog of posters built with React and TypeScript.  
At this stage , the application contains some data and basic project structure.  
The goal of this project is to demonstrate proper Git workflow, branching strategy, and preparation for automated testing.

---

## 📌 Project Purpose

- Repository setup and Git workflow
- Feature branch development
- Pull Request and Code Review
- Merge conflict resolution
- Preparation for automated testing

---

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- Git & GitHub

---

## 📂 Project Structure

- src/
- components/ → UI components
- pages/ → Application pages
- data/ → Mock data
- utils/ → Business logic functions

---

## 🚀 Run Locally

1. Install dependencies:

npm install

2. Start development server:

npm run dev

The application will be available at:

http://localhost:5173
